## 1. 要求原文（OCR，忠实转写）

**提交报告要求**

**每一组提交一份报告。**

1. 围绕课程 PJ 内容，撰写 PJ 论文报告；
2. 字数不少于 **3000 字**；字体 **宋体 小四**，行间距 **20 磅**，**首行缩进 2 字符**。中文英文均可。建议配图表。
3. 报告内容（可参考发表在权威期刊或会议的论文的内容和格式）：
   - **I 研究背景和意义**；
   - **II 研究目标和研究内容**；
   - **III 相关工作**（同类研究进展）；
   - **IV 研究方法**：1）数据集：数据获取、数据勘探（预处理）、数据存储（如有）；2）分析算法，给出算法思想、算法步骤、伪代码等；
   - **V 实验结果及分析**（有实验结果图表，对实验结果进行文字解释，并给出分析依据等）；
   - **VI 实例展现**（Demo 的截图等）；
   - **VII 总结和不足**；
   - **VIII 参考文献**（不少于 **15 篇**，并且包含 **近三年** 的）。
4. 提交时间：**2026 年 6 月 26 日 18:00 之前**。
5. 提交形式：**电子版和纸质版均需要提交**。
6. 提交方式：电子版邮件提交，文件名「**2026 年大数据课程报告—组号**」。
7. 纸质版中**每位同学都需要有签名**。
8. 报告中要**注明小组所有成员，及其工作分工**（尽可能具体详细）。
9. 同时，提交课堂上报告后修改完善的 **PPT** 以及最后一次的 **poster 海报**。

> OCR 说明：原图第 3 条的罗马数字编号存在重复（出现两个 II、两个 IV、两个 VI），系扫描/排版讹误；
> 按内容语义，正确序列应为 I–VIII 共八个部分，已在上文规范化。

## 2. 规范化报告结构（`报告.md` 即按此组织）

| 序号 | 章节 | 必含要点 |
|---|---|---|
| I | 研究背景和意义 | 问题来源、现实意义（卡口 ANPR 同行车辆挖掘的应用价值） |
| II | 研究目标和研究内容 | 目标陈述 + 本项目的三检测器 + 下游任务范围 |
| III | 相关工作 | 共现模式挖掘、轨迹表示学习、套牌检测、图社区发现的研究进展 |
| IV | 研究方法 | 1) 数据集：获取/勘探(预处理)/存储；2) 算法：思想、步骤、**伪代码** |
| V | 实验结果及分析 | **图表** + 文字解释 + 分析依据（用真实运行数字） |
| VI | 实例展现 | Demo 截图（**本版暂留占位/dummy**） |
| VII | 总结和不足 | 贡献小结 + 局限与改进方向 |
| VIII | 参考文献 | **≥15 篇，含近三年（2023–2026）** |

附：封面/成员与分工表（要求第 8 条）、致谢（可选）。

## 3. 学术报告写作最佳实践（在线检索 + 写作技能汇总）

**整体逻辑（三段式 / 纵贯式）**：围绕「提出问题—分析问题—解决问题」组织，对应 背景→方法→结果→结论。

**段落级清晰度（research-paper-writing 技能核心）**：
1. 一段只讲一个信息（one paragraph, one message），首句即点明该段主旨（topic sentence）。
2. 名词自足、术语先定义后复用，全篇术语一致。
3. 句与句之间保持显式关系（因果、对比、递进、举例）。
4. 主张—证据对齐（claim–evidence alignment）：摘要/引言中的每个论断都要有实验数据支撑，无法支撑则弱化或删除。
5. 写完每节做「逆向提纲」自检；定稿前以审稿人视角做对抗式复审（贡献/清晰度/实验强度/评测完整性/方法合理性五维）。

**图表（reviewer 常先看图表，需自解释）**：
1. 图中所有文字（坐标轴、图例、刻度）不小于正文字号；导出 ≥300 dpi。
2. 表格使用三线表风格、列首描述清楚、留白充分、字体统一。
3. 只放支撑论点的信息性图表；每图每表都有自解释的标题与说明。

**摘要**：不加注释的简短陈述，重点是结果与结论；中文摘要建议 200–300 字。

## 4. `报告.docx` 排版实现（严格对齐要求第 2 条）

| 要素 | 要求 | docx 实现（`scripts/build_report_docx.py`） |
|---|---|---|
| 正文字体 | 宋体 | `rFonts` 西文 `Times New Roman` + 东亚 `w:eastAsia="宋体"`（渲染机若无宋体，回退 Noto Serif CJK SC） |
| 正文字号 | 小四 | `Pt(12)`（小四 = 12pt） |
| 行间距 | 20 磅 | `line_spacing = Pt(20)`，`line_spacing_rule = EXACTLY` |
| 首行缩进 | 2 字符 | XML `w:ind w:firstLineChars="200"`（「2 字符」的精确表示，随字号自适应） |
| 标题 | 分级加粗 | 各级标题黑体加粗、字号递减、段前段后留白 |
| 表格 | 三线表 | 上下边框 + 表头下边框，表头加粗居中 |
| 图 | 居中 + 图题 | 图片居中，下方「图 N：…」小五号居中 |
| 字数 | ≥3000 字 | 转换器统计中文字符数并打印校验 |

提交文件名按要求第 6 条应为「2026 年大数据课程报告—组号」；本仓库内产物命名为 `报告.docx`，提交前改名即可。
